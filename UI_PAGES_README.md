# RadiusForge UI Pages — Quick Spec

- **Scale Test**: RPS planner, presets, live KPIs, RPS/latency/error charts, CSV export.
- **Performance Test**: SLO suite runner, workload mix, multi‑point scale, pass/fail, regression compare.
- **Threat Generator**: Adversarial traffic modules with safety controls; alert hooks.
- **Report**: Generate PDF/HTML with charts + config snapshot; email.
- **Topology**: Interactive canvas (see TOPOLOGY.md).
- **History/Compare**: Catalog, tags, overlay comparisons, diff.
- **Help**: Guides, error decoder, capacity calculator.
